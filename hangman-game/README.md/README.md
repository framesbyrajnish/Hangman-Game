# Hangman Game 🎮

A simple text-based Hangman game built using Python.

---

## 📌 Project Description
This project is a beginner-friendly Hangman game where the computer selects a random word and the user has to guess it letter by letter. The player gets 6 wrong attempts.

---

## 🚀 Features
- Random word selection
- 6 maximum wrong attempts
- Displays correctly guessed letters
- Simple and interactive console game

---

## 🛠️ Technologies Used
- Python
- random module
- while loop
- if-else statements
- lists and strings

---

## ▶️ How to Run
1. Download the project
2. Open terminal inside the folder
3. Run:
   python hangman.py
